# TPS_3371_TEAM_20 — Patient Referral Management System

**Course:** MIS 3371 — Capstone Project
**Milestone:** Milestone 1 — Project Definition

## Project Purpose
Clinics currently route patient referrals by phone, fax, and email, with staff checking eligibility and availability by hand. Requests get lost, duplicate referrals happen, and neither patients nor providers can see where a referral stands.

This project builds a **Patient Referral Management System**: a system to submit, validate, route, and track a single patient referral from a referring provider to a receiving department, from request through scheduling.

## Scenario
A referring provider submits a referral for a patient to receive a specific service. The system checks that required information is present, routes the referral to the correct receiving department, and tracks it through review, acceptance or rejection, scheduling, and completion — giving every stakeholder visibility into current status.
